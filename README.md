# Көше сөйлейді: Атырау

Атырау қаласының көшелері мен ескерткіштерінің тарихын көрсететін цифрлық платформа.
«Менің шағын Отаным» байқауы, «Ақылды өлке» номинациясы.
Авторлары: Мәлік Анаргүл, Мәлік Амангүл (10-сынып, Silkway мектебі). Жетекшісі: Аманжолова Марина.

Таза HTML + CSS + JavaScript. Build step те, сервер де керек емес.

## Беттер

| Файл | Не көрсетеді |
|---|---|
| `index.html` | Басты бет: карта, «Мен қайдамын?», іздеу, нысандар тізімі, Гурьев → Атырау, атаулар хроникасы |
| `object.html?id=N` | Нысан карточкасы (қысқа сілтеме: `/#nN`) |
| `route.html` | Маршруттар мен квест (`?r=center` — «Орталық бір сағатта») |
| `quiz.html` | Квиз (сұрақтар деректерден автоматты құрылады) |
| `about.html` | Жоба туралы, сауалнама диаграммасы, 9 сәйкессіздік кестесі |
| `share.html` | «Естелік қалдыру» (Google Forms) |
| `qr.html` | 13 QR-код, A4 бетінде 6-дан |
| `print.html` | Барлық нысан бір бетте, PDF-ке сақтауға |

## Деректер

- `data/objects.json` — барлық нысандар. Жаңа нысан қосу үшін соңғы нысанды көшіріп, `id`-ін өзгертіңіз. Сайт пен QR-кодтар өзі жаңарады.
  `ru` және `en` өрістері әзірге бос. Оларды толтырсаңыз, сайт сол тілде көрсетеді, бос болса қазақшасы шығады.
- `data/routes.json` — маршруттар (нысан нөмірлерінің реті).
- `data/streets.json` — тұлғалар есімімен аталған көшелер мен олардың ескі атаулары (әзірге бос, нұсқаулық файл ішінде).
- `data/survey.json` — «Дейін/кейін» сауалнама нәтижелері (пайызбен).
- `data/project.json` — жоба туралы мәлімет (гипотезаны осында жазыңыз).
- `config.js` — `BASE_URL` (сайт адресі) және `FORM_URL` (Google Forms сілтемесі).
- `images/` — фотолар: `1.jpg` … `13.jpg`, портрет `N-portrait.jpg`, «Бұрын/Қазір» үшін `N-old.jpg` + `N-new.jpg`.
- `audio/` — аудиогидтер: `1.mp3` … `13.mp3`.

## Компьютерде іске қосу

Деректер `fetch` арқылы жүктеледі, сондықтан файлды екі рет басып ашу жұмыс істемейді. Жергілікті сервер керек:

```
cd docs
python -m http.server 8080
```

Содан кейін браузерде http://localhost:8080 ашыңыз.

### Сайтты жаңарту

Файлды өзгерткен соң, осы `docs` папкасында:

```
git add -A
git commit -m "Не өзгергенін жазыңыз"
git push
```

Немесе GitHub сайтында репозиторийді ашып, **Add file → Upload files** арқылы жаңа фото/аудио/файлды жүктеңіз.
1–2 минуттан кейін сайт жаңарады.

## GitHub Pages-ке жариялау (жаңа репозиторий үшін)

1. https://github.com сайтында тіркеліп, жаңа репозиторий ашыңыз (мысалы, `atyrau`). Түрі **Public** болсын.
2. Жобаны репозиторийге жүктеңіз. `docs` папкасы репозиторийдің түбірінде тұруы керек.
   Ең оңай жолы: репозиторий бетінде **Add file → Upload files**, сосын `docs` папкасын сүйреп әкеліп, **Commit changes** басыңыз.
3. Репозиторийде **Settings → Pages** бөлімін ашыңыз.
4. **Source**: *Deploy from a branch*. **Branch**: `main`, папка: `/docs`. **Save** басыңыз.
5. 1–2 минуттан кейін сол бетте сайт адресі шығады, мысалы: `https://USERNAME.github.io/atyrau/`.
6. `docs/config.js` файлын ашып, адресті жазыңыз (соңында `/` болсын):
   ```js
   window.BASE_URL = "https://USERNAME.github.io/atyrau/";
   ```
   Google Forms дайын болса, оның сілтемесін `FORM_URL`-ге қойыңыз. Файлды сақтап, қайта жүктеңіз (commit).
7. Сайттағы `qr.html` бетін ашып, QR-кодтарды басып шығарыңыз. Әр кодты телефонмен сканерлеп, дұрыс нысанға апаратынын тексеріңіз.

**Маңызды:** QR-кодтар `BASE_URL`-ден жасалады. Адрес өзгерсе, `config.js`-ті жаңартып, QR-кодтарды қайта басып шығарыңыз.
QR-код `адрес/#n5` түріндегі қысқа сілтемені ашады. Нысанның `id`-ін өзгертпеңіз, сонда басылған QR-кодтар жұмыс істей береді.
