# Фотолар

Әр нысанның фотосын нөмірімен атап осы папкаға салыңыз:

- `1.jpg`, `2.jpg`, … `13.jpg` — негізгі фото (нысан карточкасында)
- `1-portrait.jpg` … — тұлғаның портреті (міндетті емес)
- `1-old.jpg` және `1-new.jpg` — «Бұрын / Қазір» слайдері үшін, бір ракурстан түсірілген ескі және жаңа фото (екеуі де болса ғана шығады)

Файл жоқ болса, сайт өзі әдемі placeholder көрсетеді. Фотоның авторын/дереккөзін көрсетуді ұмытпаңыз.
